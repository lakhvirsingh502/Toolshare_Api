# ToolShare API

A FastAPI backend for sharing and reserving equipment.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Redis
- Celery
- Docker
- Pytest
- GitHub Actions

## Features

- User authentication with JWT
- Equipment management
- Equipment reservations
- Reservation cancellation
- Redis rate limiting
- Background tasks
- Celery tasks
- Automated testing with Pytest
- Dockerized development environment
- CI/CD with GitHub Actions
